# 논문 연구·실험 진행 체크리스트

기준일: 2026-09-16. 기존 TODO.md가 이동한 현재 파일은 docs/02_TODO.md이다. 다음 실행의 구체적 조건과 완료 기준은 [01_PLAN.md](01_PLAN.md)를 따른다.
