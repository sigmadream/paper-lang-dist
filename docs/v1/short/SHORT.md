# 1차 실험 결과 요약 (v1.1)

정리일: 2026-09-16. 완료 실험의 수치는 통합 summary.json과 RESULT_v1.1.md를 기준으로 한다. 이 요약은 일반적인 언어 거리나 의미 동치의 검증 완료를 뜻하지 않는다.

## 1. 실험과 판정

- 목표: 빠른 기능 실패를 짧은 언어 거리로 오인하지 않도록 실패율과 성공 조건부 시간·구조 변화를 분리.
- 모델: Qwen2.5-Coder 7B Instruct, Q4_K_M, temperature=0, seed=20260911; 프롬프트 1종.
- 규모: 원본 20문제 중 19문제 검증 통과, C·Java·Python 경유 × 3회 = 171건. 예비 15건은 미합산.
- SF(Stabilized and Functional): K=10 이내 후보 안정화 도달, 모든 중간·복원 단계의 fixture 통과, 확인 c회 동안 후보 해시와 기능 검사 통과 유지.
- 첫 왕복은 t=1. tau는 후보 시점이며 추가 확인 5회는 포함하지 않는다.
- 원본 IPOP_1260은 입력 형식 문제로 사전 제외했다. 모델의 기능 오류로 세지 않는다.

## 3. 실패와 확인 효과

- 성공 101건, 실패 70건. 실패는 기능 오류 68건(오답 33, 컴파일 19, 실행 오류 13, 실행 시간 초과 3)과 확인 해시 변경 2건이다.
- 순환·탐색 상한 도달·출력 형식 오류는 0건이다.
- c=0 성공 104건 중 첫 확인에서 3건이 탈락했다. IPOP_9935의 C는 오답, Java·Python은 테스트를 통과한 상태의 해시 변경이다.
- c=1..5는 성공 101건으로 동일했다. 이는 확인 횟수 축소를 후속 검증할 근거이며 영구 안정화나 확인 2회의 충분성을 입증하지 않는다.
- 실패는 평가 분모와 d_SF에 남기고 성공 조건부 tau·Delta_0에서는 제외한다.

## 4. 성공 조건부 시간과 구조 변화

c=5 성공 집합의 중앙값이다. Delta_0는 원본과 후보 C++의 1-유사도이며, 값이 작을수록 해당 표현에서 유사하다.

| 경유 언어 | 성공 n | tau 중앙값 [Q1, Q3] | Delta_0 Dice | Delta_0 sequence | Delta_0 AST |
| :--- | ---: | :--- | ---: | ---: | ---: |
| C | 26 | 2 [2, 3] | 0.156 | 0.202 | 0.360 |
| Java | 35 | 2 [2, 2] | 0.140 | 0.155 | 0.212 |
| Python | 40 | 2 [2, 3] | 0.166 | 0.292 | 0.482 |

AST는 성공 101/101건 측정됐다. tau 중앙값이 같다는 사실만으로 속도 분포의 동등성을 주장할 수 없다. 경로마다 성공 문제 구성이 달라 구조 변화량의 차이를 순수한 언어 효과로 해석하지 않는다.

IPOP_10988의 Python 경로는 세 run 모두 tau=3과 확인 5회를 통과했지만 함수 분리·루프 변경으로 AST 변화량이 0.9211이었다. 이는 기능 검사 통과와 구조 변화가 함께 나타날 수 있음을 보여주며, 두 성분의 통계적 독립성을 증명하지 않는다.

이전 요약의 C·Java sequence 중앙값 0.163/0.137을 원본 집계의 0.202/0.155로 정정했다. 2절의 95% 구간은 성공률에 대한 구간이며 실패율의 구간과 구별한다.

## 5. 감사와 해석 범위

- 완료 감사 171/171건 통과. 논리 요청/API 시도 1,602/1,602회, 오류·재시도·절단·형식 오류·미해결 인프라·미완료 관측 0건.
- 번역·실행 경과 시간 83.09분, 입력 1,189,407토큰, 출력 294,357토큰. 최종 후처리 시간은 제외.
- 비교 가능한 240개 위치 중 205개(85.4%)에서 세 run의 해시가 모두 일치. 미도달·실패 46개와 단계 불일치 11개 위치는 별도 기록.
- 입력 파일 190개를 문제별로 중복 제거하면 총 70개이며, 8문제는 프롬프트에도 제시된 입력 1종뿐이다.
- 단일 모델·프롬프트, 병렬 실행, 툴체인과 시간 제한의 영향을 언어 효과와 분리하지 못했다.
- C의 높은 실패율을 "언어의 엄격성"만으로 설명하지 않는다. stdbool.h 누락처럼 모델이 대상 언어의 요구를 충족하지 못한 사례가 포함된다.
- 기록상 오류 0건과 전수 감사 통과는 관측 정합성의 근거이며, 인프라 영향의 완전 배제나 완전한 재현성을 뜻하지 않는다.
