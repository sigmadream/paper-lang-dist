# 변경 전 데이터 보관

[v2-a-before-quality](v2-a-before-quality/)는 논문용 품질 개선 직전의 40문제·400쌍, 프롬프트용 명세·예제, 기준 코드, 메타데이터, 설정 및 P1 템플릿을 보관한 스냅샷이다. 활성 자료는 `problem/<문제 ID>/`에 있다.

내부 설정과 메타데이터 경로는 저장 당시 위치를 기준으로 한다. 이 보관 설정을 그대로 실행용으로 사용하지 않는다. IPOP의 원래 공개 예제 전체를 평가에서 제외하기 위해 생성기와 검증기가 보관된 명세를 읽는다.

기존 400개 평가 입력·정답과 40개 기준 코드, 각 문제의 첫 예제는 활성 자료에서도 바이트 단위로 보존한다. 변경 내역과 검증 결과는 [품질 점검](../metadata/quality/README.md)을 참고한다.
