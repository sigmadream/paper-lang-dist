# 논문 출판 계획

> 8월 논문 출판을 목표로 작성된 단계별 진행 체크리스트입니다. 최우선 연구 방향 3가지를 중심으로 핵심 가설을 증명하고 논문을 작성하는 일정으로 구성했습니다.

---

## Phase 1: 이론적 기반 정립 및 지표 설계(1주)
"고정점 개념의 수학적 정교화 및 다중 관점의 언어 거리 측정 지표(Metric) 구체화"

- [ ] 의미 생존 보정 고정점 거리 이론화 (최우선 축 1)
  - [ ] 단순 반복 횟수 의존에서 벗어나, 의미 보존 실패(0%) 시의 페널티 모델링
  - [ ] LLM 왕복을 '확률적 전이 연산자'로 정의하고, '의미 등가류에 대한 기대 hitting time' 산출 공식 설계
- [ ] 다중뷰 프로그래밍 언어 거리 지표 설계 (최우선 축 2)
  - [ ] 표면적 구조(MOSS) 외에 AST 편집 거리(TSED), 데이터 흐름 그래프(CSSG) 등 구조적/의미적 측정 방식 통합
  - [ ] 임베딩 기반 유사도(CodeBLEU, CodeBERTScore)와 실행 통과율(Trace)을 결합한 통합 벡터 구성 방안(차원축소, metric learning) 마련

## 🏗️ Phase 2: 대규모 코퍼스 준비 및 실험 환경 구축(1주)
"다언어/다모델 테스트를 위한 벤치마크 연동 및 샌드박스 세팅"

- [ ] 다언어·다모델 실험 인프라 구축 (최우선 축 3)
  - [ ] MultiPL-E, XCodeEval 등 대규모 다언어 벤치마크 셋 확보 및 전처리
  - [ ] 분석 대상 8~12개 프로그래밍 언어 선정 및 격리된 실행 환경(Sandbox) 구축
  - [ ] 테스트할 LLM 계열(GPT, Qwen, CodeT5, Code Llama 등) API 연동 및 로컬 인퍼런스 서버 세팅
- [ ] 실험 파이프라인 자동화
  - [ ] 언어 $A \to B \to A$ 왕복 번역 및 고정점(Fixed-point) 감지 자동화 스크립트 작성
  - [ ] 다중뷰 지표(MOSS, TSED, CodeBLEU 등) 자동 추출 및 DB 저장 파이프라인 구축

## 🚀 Phase 3: 본 실험 수행 및 데이터 수집(2주)
"설계된 파이프라인을 바탕으로 대규모 왕복 번역 실험 진행"

- [ ] 본 실험 실행
  - [ ] 설정된 LLM 모델들과 언어 쌍에 대해 벤치마크 코퍼스 왕복 변환 수행
  - [ ] 각 시도별 고정점 도달 여부, 반복 횟수, 의미 손실(Test fail) 데이터 로깅
- [ ] 데이터 정합성 검증
  - [ ] 누락되거나 오류가 발생한 변환 케이스(Timeout, Compilation Error 등) 재수행 및 디버깅

## 📊 Phase 4: 통계적 분석 및 시각화(1주)
"수집된 데이터를 바탕으로 언어 효과와 모델 효과를 분리하고 시각화"

- [ ] 언어 효과 vs 모델 효과 통계적 분리 (최우선 축 3)
  - [ ] 혼합효과 모형(Mixed-effects Model) 또는 계층 베이지안 모형을 이용해 분산 분해 분석 수행
  - [ ] 프롬프트 요인 및 과제 난이도 통제 하에 "진짜 언어 거리" 추출
- [ ] LLM 유도 프로그래밍 언어 계통도(Phylogeny) 구축
  - [ ] 도출된 다중뷰 언어 거리 행렬을 기반으로 클러스터링 및 계통도 트리 시각화
  - [ ] 기존 인간 학습 난이도 및 언어 계보학 기반 연구 결과와 비교 분석
- [ ] (Optional) 2차 우선 연구 요인 분석
  - [ ] 방향성 거리 비대칭성 및 언어 기능/패러다임에 따른 붕괴 원인 마이크로벤치마크 분석

## 📝 Phase 5: 논문 초안 작성(1주)
"결과물 정리 및 학술 논문 형태로 집필"

- [ ] 논문 아웃라인(Outline) 확정
  - [ ] Introduction (문제 제기, 기존 MOSS/단일 모델 기반 접근의 한계)
  - [ ] Theoretical Framework (확률적 고정점 및 다중뷰 지표 정의)
  - [ ] Experimental Setup (벤치마크, 평가 모델 및 언어 세팅)
  - [ ] Results & Analysis (언어/모델 효과 분리, 언어 계통도 시각화)
  - [ ] Discussion & Conclusion
- [ ] 섹션별 본문 작성 및 그림/표(Figure/Table) 삽입
- [ ] 공동 연구자 리뷰 및 논문 피드백 반영 (Revision)

## 🎓 Phase 6: 투고 및 출판 대응(1주)
목표: TIIS(KSII Transactions on Internet and Information Systems) 학회/저널 투고 및 심사 대응을 통한 8월 출판 완료- 

- [ ] 타겟 학회/저널 선정 및 포맷팅 적용 (8월 출판 일정에 맞는 곳: 예시 - ACL, EMNLP, ICML, OOPSLA 등 일정 역산하여 투고)
- [ ] 논문 투고 진행 (Submission)
- [ ] Reviewer 코멘트 분석 및 Rebuttal (저자 답변) 작성
- [ ] 필요 시 추가 실험(Minor revision) 수행
- [ ] Camera-ready 버전 제출
