# IPOP_1620: 나는야 포켓몬 마스터 이다솜

서로 다른 이름 N개와 질의 M개를 읽고 이름과 1-based 번호를 상호 조회한다.

## 제약과 입력

첫 줄 N M, 각각 1..100000. 이후 N줄에 서로 다른 이름, 이후 M줄에 질의 하나씩. 이름은 길이 2..20의 영문자로 첫 글자만 대문자이거나 마지막 글자만 대문자다. 이름 질의는 사전에 존재하고 숫자 질의는 1..N이다.

## 출력

이름 질의에는 입력 순서의 1-based 번호, 번호 질의에는 해당 이름을 질의 순서대로 한 줄씩 출력한다.

예제 입력과 출력은 프롬프트의 별도 예제 구역에 제시한다. 문제 명세의 모든 유효 입력에 대한 동작을 보존한다.
