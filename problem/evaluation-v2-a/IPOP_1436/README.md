십진 표현에 666을 포함하는 수 중 N번째 수를 출력한다.

[기존 문제 명세](../../IPOP_1436.md) · [원문](https://www.acmicpc.net/problem/1436)

- 기준 계산: 정수 순회와 문자열 검색
