# RTT 언어 거리 실험 및 rttdist 개선 체크리스트

기준일: 2026-09-18. 설계와 용어는 [01_PLAN.md](01_PLAN.md)를 따른다. 이번 범위는 C++·Haskell·Prolog 사이 6개 왕복 경로, 공통 문제 10~20개, 기능 성공률 P_sf·유사도 Sym·수렴 거리 d_n의 측정, 다른 LLM을 지원하는 `rttdist` 개선이다.

2026-09-18 본 실험을 완료했다. 공통 15문제의 45개 기준 코드·585개 평가 실행, 예비 18관측, 본 90관측과 원본 대조 감사를 마쳤다. 본 결과는 성공 9건·평가 실패 81건·미평가 및 미완료 0건이다. [결과 보고서](RESULT_FPS.md), [실행 기록](FPS_EXPERIMENT_LOG.md), [Word 초록](abs/33rd_abstract_sample.docx)에 근거를 연결했다. 사용자 지시에 따라 두 번째 LLM·외부 endpoint 실측·모델 비교는 이번 범위에서 유예한다. 해당 미체크 항목은 완료를 의미하지 않으며 후속 과제로 유지한다.

## 5. 핵심 검증

완료 기준: 새 측정 계약의 경계 조건과 provider 교체·재개 동작을 확인하고, 기존 관련 검사도 통과한다.

- [x] 초기 상태를 포함하여 `A₀ → B₀ → A₀`의 FPS가 2인지 검사한다.
- [x] `A₀ → B₀ → A₁`에서 근사 수렴하면 d_n=3인지 검사한다. 첫 왕복이라는 이유로 1로 기록하지 않는다.
- [x] `A₀ → B₀ → A₁ → B₀ → A₁`의 FPS가 3이며 재등장으로 증가하지 않는지 검사한다.
- [x] 동일 문자열이라도 언어가 다르면 별개 상태인지, 서로 비슷한 코드라도 동일하지 않으면 별개인지 검사한다.
- [x] 원본과 높은 유사도를 보이더라도 인접 복원 코드의 Sym_adj가 낮으면 계속한다.
- [x] 0.85 직전·정확히 0.85·직후 점수의 경계 처리를 검증한다. 반올림 표시값으로 판정하지 않는다.
- [x] FPS=10에서 기능·수렴 조건을 만족하면 성공으로 인정한다.
- [x] FPS=10에서 임계값 미달이면 별도 실행 예산 안에서 계속하고, 중복 출력으로 FPS가 증가하지 않는지 검사한다.
- [x] 새 상태로 FPS=11이 되면 추가 번역을 하지 않는다. 높은 유사도도 이 상한을 무효화하지 않는다.
- [x] 중간 언어 단계에서 FPS=11이 되면 복원 호출 없이 종료한다.
- [x] FPS가 증가하지 않는 비수렴·진동에서도 별도 번역 예산으로 종료하며 FPS 초과와 다른 상태로 기록한다.
- [x] 중간·복원 단계 각각의 컴파일/로딩·실행·오답·시간 초과가 정확히 분류된다.
- [x] 모든 기능 검사가 통과한 상한 도달 관측에서 P_functional과 P_sf가 구분된다.
- [x] 유사도 NA와 실제 0, text 유사도와 C++ 전용 유사도를 구분한다.
- [x] 동일 소스, 공백·주석·변수명 변화, 연산자·분기 변경, 짧은 코드, 공통 래퍼의 영향을 점검한다.
- [x] API 재시도와 중단·재개가 거리를 늘리거나 완료 응답을 새로 생성하지 않는다.
- [x] provider의 서로 다른 응답·오류·미지원 옵션을 모의 응답으로 검증한다.
- [x] 일반 실행 경로와 새 실험 실행 경로가 모두 공통 provider를 사용하는지 확인한다.

## 진행 순서

`측정 계약 확정 → 공통 샘플 검증 → 라이브러리 개선·핵심 검사 → 예비 실행 → 설계·예산 동결 → 본 실행 → 분석·재현·보고`

거리 단위는 FPS 크기이며, 이번 단일 모델 범위의 구현·검증·예비·본 실행·보고를 완료했다. 모의 provider 검사와 실제 모델 실험은 구분한다. 임계값 민감도는 이번 동결 범위에 등록하지 않았으며 높은 임계값의 미관측 결과를 추정하지 않았다. 보조 분기 변화 진단은 본 실행 시작 뒤 수행한 후속 진단이고 임계값이나 관측을 변경하지 않았다. 기존 Scala 전용 검사 5개는 도구 부재로 제외했으며 이번 세 언어의 완료 범위와 구별한다.
