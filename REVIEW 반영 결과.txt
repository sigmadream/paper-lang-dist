# 리뷰 내용

> 본 연구는 2026년 한국인터넷정보학회에서 발표할 가치가 있다고 보임. 왕복 번역과 고정점이라는 독창적인 프레임워크를 통해 모호했던 언어 간 유사도를 정량화한 접근은 좋은 접근이라고 생각되나, 실험에 사용된 문제의 다양성과 표본 크기는 다소 한계성이 있어, 이를 확대하여 분석 결과의 보편성을 더욱 보완할 필요가 있어 보임.

# 리뷰 반영 및 수정 사항

1. 본 논문의 전체적인 톤을 "탐색적 연구"로 명확히 함

- 본 연구의 목적은 다음과 같다. 첫째, C++를 기준 언어로 C, Java, Python을 오가는 왕복 번역을 통해 프로그래밍 언어 간 거리를 측정하는 프레임워크의 가능성을 탐색적으로 살펴본다. 둘째, 동일 조건에서 오픈소스 모델(qwen2.5-coder)과 상용 모델(gpt-5.4)의 번역 양상을 비교해, 모델 고유의 특성이 언어 간 거리 측정에 미치는 영향을 분석한다.

2. (표 4) 언어쌍별 MOSS 유사도 분포로 변경, 표준편차를 표기해서 작은 데이터에서 발생하는 편차를 명확하게 제시

- 표 4는 각 언어 쌍에 대해 MOSS를 사용한 유사도 측정 결과(평균 및 표준편차)를 나타낸다. gpt-5.4는 세 언어 쌍 모두에서 평균 25~37%대의 MOSS 점수를 기록하며, 대상 언어에 관계없이 원본 코드의 뼈대를 일정 수준 유지하려는 일관성을 보여준다. 반면, qwen2.5는 대상 언어에 따라 유사도가 크게 엇갈리는 양극화 현상을 보인다. C++에서 Java로 왕복한 경우에는 평균 63.8%로 높은 구조적 유사도를 유지했으나, C 변환 시에는 평균 19.3%로 낮아졌으며, Python 변환에서는 0.0%를 기록했다. 특히 qwen2.5에서 파이썬으로 변환 후 다시 C++로 번역된 코드의 MOSS 수치를 보면 평균과 표준편차 모두 0.0으로 나오는데, 이는 구조적 의미로 해석할 수 있다. 즉, 역번역 과정에서 원본 C++ 프로그램의 구조적 흔적이 완전히 사라지는 형태로 전면 재작성(rewrite)되었음을 의미하며, gpt-5.4가 변환 과정에서 원본 문법 및 알고리즘의 뼈대를 최대한 보존하면서 번역하려는 경향이 더 강하다고 볼 수 있다. 두 모델 모두 전반적으로 큰 표준편차를 동반하고 있어, 개별 문제의 알고리즘 특성에 따라 구조 변형 정도에 적지 않은 편차가 존재함을 유의해야 한다.

3. 제언을 한계 및 "논의 및 향후 과제"로 변경

- 본 연구는 5개의 알고리즘 문제라는 소규모 코퍼스를 활용한 탐색적 연구로, 관찰된 모델의 번역 경향성과 언어 간 거리를 일반화하기에는 표본 크기의 한계가 있다. 조기 실패가 빈번한 언어 쌍에 대한 성능 저하 요인 분석과 함께, 문제의 다양성과 개수를 확대한 대규모 검증이 필요하다.

4. 결론 부분 요약, [2] (표 4)에 대한 해석 부분이 늘어나서 결론 부분을 좀 더 짧게 요약

- 실험 결과, qwen2.5는 모든 언어 쌍에서 균일한 수렴 속도(평균 2.2~2.4회)와 범용적인 변환 능력을 입증했다. 반면 gpt-5.4는 C 변환 시 높은 성공률을 보였으나 고정점 도달까지 큰 구조적 재구성(평균 5.4회 반복)을 거쳤으며, Java와 Python에서는 조기 실패하는 극단적 성능을 보였다. 이를 통해 두 모델이 코드를 번역하고 구조를 다루는 방식(MOSS)에 확연한 차이가 있음을 확인했다.
향후 연구에서는 이러한 번역 성향의 차이를 심층 분석하고, 실무 요구(구조 유지 vs 단순 실행)에 맞춰 최적의 모델을 자동 할당하는 프레임워크를 개발할 계획이다.
