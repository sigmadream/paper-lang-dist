고정점을 이용한 프로그래밍 언어 거리 측정(Measuring the Distance of Programming Languages Using Fixed-Points) 후속 논문 관련 연구 방향 검토

한상곤, 우균 (부산대학교 대학원 정보융합공학과)

---

<!-- _header: 1. 기존 연구 요약: 핵심 아이디어 -->

### LLM 기반 왕복 번역과 언어 간 "거리"

1. 왕복 번역(Round-Trip Translation): 언어 $A$를 $B$로 번역 후 다시 $A$로 번역할 때 발생하는 정보 손실과 구조적 변화를 "거리"로 해석
2. 고정점(Fixed-point): 반복 변환 시 코드가 더 이상 변하지 않는 지점 도달 여부와 반복 횟수 측정
3. 구조와 의미의 분리: MOSS(구조적 유사도)와 실행 테스트(의미 보존 여부)를 병행하여 차이 정량화

> Miltiadis Allamanis, Sheena Panthaplackel, and Pengcheng Yin. 2024. Unsupervised evaluation of code LLMs with round-trip correctness. In Proceedings of the 41st International Conference on Machine Learning (ICML'24), Vol. 235. JMLR.org, Article 44, 1050–1066.

---

<!-- _header: 2. 우리 연구의 학술적 위치 (1/4) -->

### 2.1 왕복 번역과 Round-Trip Correctness (RTC)

- 개념: 코드 $\to$ 자연어(설명) $\to$ 코드로 변환하여 원본과 의미적 동치인지 테스트하는 비지도 평가 기법
- 관련 연구: Allamanis 등 (ICML 2024)은 코드 LLM의 성능 평가를 위해 RTC를 도입하고, 이것이 기존 벤치마크 결과와 높은 상관관계가 있음을 증명함

---

<!-- _header: 2. 우리 연구의 학술적 위치 (2/4) -->

### 2.2 언어 거리와 유사도 측정 이론 (자연어 중심)

- 개념: 자연어의 계통도 분석이나 교육 난이도 측정을 위해 언어 간 거리를 정량화하는 연구 (예: DistaLs)
- 관련 연구: 품사(POS) n-gram 분포의 Jensen-Shannon 거리, 어휘 유사도, 개념 임베딩 등 다양한 메트릭을 통해 '언어 거리 행렬'을 구축

> Filippo Petroni, Maurizio Serva, Measures of lexical distance between languages, Physica A: Statistical Mechanics and its Applications, Volume 389, Issue 11, 2010, Pages 2280-2283,ISSN 0378-4371, https://doi.org/10.1016/j.physa.2010.02.004.
---

<!-- _header: 2. 우리 연구의 학술적 위치 (3/4) -->

### 2.3 코드 유사도와 정보 거리

- 개념: 두 프로그램 코드 사이의 구조적, 정보적 유사성을 정량화
- 관련 연구: 
  - 표절 탐지 지표: MOSS (토큰 k-gram 및 Winnowing 알고리즘 기반)
  - 정보 이론적 거리: Kolmogorov 복잡도에 기반한 NID (Normalized Information Distance), 두 객체 상호 변환을 위한 최단 프로그램 길이를 보편적 거리로 정의

> - Schleimer, A., Wilkerson, H., & Aiken, A. (2003). Winnowing: Local Algorithms for Document Fingerprinting. Proceedings of the 2003 ACM SIGMOD International Conference on Management of Data.
> - BMoss: Reconfigurable Hardware Accelerator for Scalable Plagiarism Detection (ACM, 2024) 
> - Li, M., Chen, X., Li, X., Ma, B., & Vitányi, P. M. B. (2004). The Similarity Metric. IEEE Transactions on Information Theory, 50(12), 3250–3264.
---

<!-- _header: 2. 우리 연구의 학술적 위치 (4/4) -->

### 2.4 우리 연구와 기존 연구의 차별점

- 기존 연구가 모델의 번역 성능 평가를 목적으로 했다면, 우리 연구는 이를 프로그래밍 언어 간 거리(구조적 이질성)를 측정하는 도구로 독창적으로 재해석함
- 자연어 중심의 거리 지표를 코드의 특성(예약어 집합, 타입 시스템, 메모리 모델, 추상 구문 트리 등)에 맞게 투영할 수 있는 작은 토대를 마련함
- 단순한 토큰 비교나 이론적 정보 거리를 넘어, 실행 기반 의미 보존(테스트 통과)이라는 동적 기준을 왕복 고정점 도달 횟수와 결합한 측정 프레임워크

<!-- _header: 3. 후속 연구 방향 제안 -->

1. 언어 거리 행렬과 군집 분석 (다중 언어 확장)

3. LLM·프롬프트 요인 분석과 수렴성 검증 (모델 특성 통제 및 분석)

4. 대규모 코퍼스와 실제 시스템 코드 적용 (외적 타당도 확보)

<!-- _header: 3.1 언어 거리 행렬과 군집 분석 -->

### 다언어 지형도(Phylogeny) 구축

- 연구 개요: 특정 언어쌍을 넘어 다수 프로그래밍 언어 간 왕복 고정점 반복 횟수, 의미 보존률, 구조적 유사도를 측정하여 "프로그래밍 언어 거리 행렬" 구축

- 목표: 언어별 특성(타입 시스템, 메모리 관리 등)을 수치화하여 클러스터링 기반의 언어 지형도 완성

<!-- _header: 3.2 거리 지표의 정교화 -->

### 구조적/의미적 메트릭의 고도화

- 연구 개요: 토큰 기반 MOSS의 한계 극복을 위해 고차원 의미/구조 메트릭 결합
- 핵심 지표:
  - `TSED`: AST(추상 구문 트리) 편집 거리 기반 구조 유사도 측정
  - `CSSG`: 프로그램 의존 그래프(PDG) 기반 제어/데이터 흐름 유사도 측정

<!-- _header: 3.3 LLM 요인 분석과 신뢰도 검증 -->

### 모델 특성 분리 및 수렴성(Convergence) 추적

- 연구 개요: 관측되는 거리가 '언어 고유의 차이'인지 'LLM의 성능/정책'인지 분리 
- 핵심 가설 검증: 일반 LLM vs 코딩 특화 LLM의 편차를 분석하고, 언어 모델 성능이 고도화될수록 지표가 어떻게 수렴하는지 추적
