# LC_0387: First Unique Character In A String

한 번만 등장하는 첫 문자의 0-based 인덱스를 출력하고 없으면 -1을 출력한다.

## 제약

문자열 길이 1..100000; 영문 소문자.

## 표준입출력 계약

첫 줄 전체가 문자열이다. 공백도 문자로 보존하며 LC_0003은 빈 줄을 허용한다.
출력은 정수 하나 또는 공백으로 구분한 정수 배열이다. 참/거짓은 각각 1/0으로 출력한다. 인덱스는 0부터 시작한다.

## 공개 예제

```text
leetcode
```

출력:

```text
0
```
