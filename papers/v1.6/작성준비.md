# v1.6 원고 작성 준비

2026-11-19에 v1.5를 바탕으로 [국문 원고](manuscript.md)와 [편집용 Word 문서](v1.6.docx)를 작성하였습니다. 아래 항목은 공동저자 검토와 제출 전 편집에 사용할 점검 순서입니다. 실제 작성·문헌 확인·수치 대조 범위는 [작성·검증 기록](원고작성-검증기록.md)에 남겼습니다.

## 권장 작성 순서

1. 방법 장을 먼저 작성해 승인 설계, 코퍼스 출처, 캠페인별 동결 계약과 사용한 평가 도구·버전·설정을 대조해 주십시오.
2. 결과 장에 Flash와 GLM의 공식 원관측과 유효 분모를 제시해 주십시오. GLM HTTP 524 감사와 사용자 요청에 따른 사후 측정 실패 집계는 집계 규칙과 함께 별도 표로 인용해 주십시오.
3. 논의 장에서 기능 검사, JPlag 측정, 확인 왕복, 시간 제한과 모델 응답의 제약을 사례별로 서술해 주십시오. 무효·미저장·확인 불가는 각각 별도 상태로 유지해 주십시오.
4. 원고에 수록한 선행 연구의 원문·판본·본문 인용 위치를 최종 검토해 주십시오. 초기 자료 준비 후 이번 집필에서 실제 사용한 문헌의 공식 원문과 저장된 선행 논문을 확인하였으며, 추가 문헌이 필요하면 같은 방식으로 출처와 주장 범위를 확인해 주십시오.
5. 결론은 기술통계와 이 자료에서 실제 확인한 관측에 한정해 주십시오. 그림이 근거 표의 동일 결과를 보여 주는지 확인한 뒤 초록을 작성해 주십시오.

## 출판 전 확인할 제한

- GLM 사후 측정 실패 세 건은 기능 시험 통과 후 측정 실패로 분류하였습니다. Flash에서는 측정 불가로 각 임계치에서 무효가 된 세 슬롯을 공식 분류에 유지합니다.
- Flash와 GLM의 300슬롯 저장은 자료 수집과 구조 감사의 결과입니다. 임계치별 분석 완전성은 두 캠페인 모두 충족하지 못했습니다. 저장 보고 재현 성공은 이 판정을 바꾸지 않습니다.
- 0.85의 확증 비교 및 전체 순위를 지지한다고 주장할 근거가 부족합니다. 0.80·0.90, 사전 재귀군과 비교군, 단계별 확인은 기술 결과로 제시해 주십시오.
- Pro 중단 두 건의 관측과 추정 비용, 불명 요청 및 예약을 각 캠페인에 귀속해 주십시오. Flash나 GLM과 통합 추정치로 계산하지 마십시오.
- v1.5는 v1.6과 문제 교체와 중단 규칙이 다릅니다. 두 판본의 직접 합산과 개선율 계산은 적용하지 마십시오.
- 제한된 평가 입력에서 기능 통과가 확인되었습니다. 모든 입력의 의미 동등성과 JPlag 기반 구조 해석에는 별도 근거가 필요합니다.
