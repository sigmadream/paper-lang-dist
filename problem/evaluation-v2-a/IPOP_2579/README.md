# IPOP_2579: 계단 오르기

1칸 또는 2칸씩 이동하고 세 계단 연속 방문을 금지하며 마지막 계단까지 점수를 최대화한다.

[기존 문제 명세](../../IPOP_2579.md) · [원문](https://www.acmicpc.net/problem/2579)

입력은 이 평가 묶음에서 자체 생성했다. GitHub 저장소의 공식 테스트를 수집한 것이 아니다.
기존 입력 파일 전체와 문제 본문의 입력 예제를 공백 정규화 후 제외했다. 모든 정답은 아래 두 방식으로 교차 검증했다.

- 기준 계산: 점화식 DP
- 독립 검증: 합법적인 계단 이동 경로 완전탐색

이 묶음에서 채택한 LeetCode 대응 풀이는 없다. 로컬 명세와 독립 검증기를 사용한다.

| 사례 | 목적 | 입력 | 정답 |
|---|---|---|---|
| case01 | 최소 계단과 점수 | [입력](case01.inp) | [정답](case01.out) |
| case02 | 점수 상한 | [입력](case02.inp) | [정답](case02.out) |
| case03 | 두 계단 | [입력](case03.inp) | [정답](case03.out) |
| case04 | 세 계단 연속 금지 | [입력](case04.inp) | [정답](case04.out) |
| case05 | 양끝 고득점 | [입력](case05.inp) | [정답](case05.out) |
| case06 | 동일 점수 | [입력](case06.inp) | [정답](case06.out) |
| case07 | 증가 점수 | [입력](case07.inp) | [정답](case07.out) |
| case08 | 감소 점수 | [입력](case08.inp) | [정답](case08.out) |
