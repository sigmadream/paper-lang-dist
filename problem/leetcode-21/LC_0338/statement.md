# LC_0338: Counting Bits

0부터 N까지 각 정수의 이진 표현에서 1의 개수를 순서대로 출력한다.

## 제약

0<=N<=100000. 기준 구현은 내장 popcount를 사용하지 않는다.

## 표준입출력 계약

첫 줄 정수 N.
출력은 정수 하나 또는 공백으로 구분한 정수 배열이다. 참/거짓은 각각 1/0으로 출력한다. 인덱스는 0부터 시작한다.

## 공개 예제

```text
2
```

출력:

```text
0 1 1
```
