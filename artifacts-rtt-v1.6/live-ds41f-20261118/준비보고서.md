## 공식 문서와 옵션

조회 시점은 2026-11-18 04:03:13 UTC이며 [조회 기록](공식문서-조회.json)에 출처·관련 내용·단가·생략 이유를 저장하였습니다. 정확 ID는 [Command Code 모델 목록](https://commandcode.ai/docs/reference/cli/models)에서 확인하였고, [Flash 모델 페이지](https://commandcode.ai/models/deepseek-v4-1-flash)와 [DeepSeek 공식 가격](https://api-docs.deepseek.com/quick_start/pricing/)에서 피크 입력 0.30·출력 1.20·캐시 입력 0.006달러/백만 토큰을 교차 확인하였습니다. 피크는 UTC 평일 01–04 및 06–10이며, 비용 추정에는 실행 시간대와 관계없이 피크 단가를 사용합니다.

`max_tokens=16384`와 `reasoning_effort=low`를 유지합니다. [공식 채팅 API](https://api-docs.deepseek.com/api/create-chat-completion/)가 허용하는 최대 토큰 범위와 [추론 모드 문서](https://api-docs.deepseek.com/guides/thinking_mode/)의 low 지원을 확인하였습니다. temperature는 추론 모드 미지원으로 생략합니다. Flash의 top_p는 추론 모드에서도 지원되므로 생략 이유를 미지원으로 쓰지 않고 기존 실험 조건 유지를 위해 추가하지 않았다고 기록합니다. seed도 추가하지 않습니다. 문서상 기본값과 실제 응답 실효값을 구분하며, 미보고 실효 설정과 실제 청구액은 null로 유지합니다.

endpoint는 `https://api.commandcode.ai/provider/v1/chat/completions`로 유지합니다. APIProvider가 요청·응답의 정확 모델을 검사하며 Pro·fast·ultrafast 응답을 보존한 뒤 거부하는 실제 공급자 경로 모의 검사가 통과하였습니다. 해당 모의 전송에서는 요청 모델·옵션·endpoint와 생성 옵션 세 가지의 생략을 직접 확인하였습니다.

## 독립 검토 연결과 남은 실행

검토자는 새 소스·설정·검사·manifest·이 보고서와 관련 검증 근거를 실제로 검토하고 `independent-review.json`을 별도로 작성해 주셔야 합니다. 과거 검토 JSON이나 source-manifest를 통과 근거로 복사하지 않았고, 이 작업자가 독립 검토자로 표시된 JSON도 만들지 않았습니다.

신규 검토 관문에는 `passed=true`, `reviewer`, 이 작업자와 다른 `reviewer_session_id`, 정확한 `campaign_id` 및 `model_id`, 실제 `report_path`·`report_sha256`, 새 manifest의 `prepared_manifest_path`·파일 바이트 SHA-256인 `prepared_manifest_sha256`, 그리고 새 manifest `files` 전체 67개의 현재 해시를 포함하는 `source_hashes`가 필요합니다. 이는 기술 검토 관문이며 사용자 추가 승인 절차가 아닙니다.

실제 독립 검토를 받으면 현 소스·보고서·manifest 해시와 일치를 확인하고 지정 uv 명령으로 독립 OK 1회→12슬롯→완전성 감사→새 동결→300슬롯→공식 보고·재현을 실행합니다. 524·unknown·inflight가 남으면 자동 재전송·원장 초기화·실패 대체·캠페인 재시작을 하지 않고 실패로 보고합니다. 이번 준비 단계에서는 인증 파일·값을 읽거나 출력·복사하지 않았으며, 실제 유료 실행·슬롯 수집·모델 응답·청구·최종 비밀정보 감사는 아직 수행 전입니다.
