고정점을 이용한 프로그래밍 언어 거리 측정(Measuring the Distance of Programming Languages Using Fixed-Points)

한상곤, 천준석, 우균 (부산대학교 대학원 정보융합공학과)

---

<!-- _header: 서론 -->

### 연구 배경
- 프로그래밍 언어 사이의 유사도는 암묵적인 기준이 대부분이며, 정량적 기준이 부재함
- 대규모 언어 모델(LLM)을 활용한 언어 간 거리의 정량적 측정법 제안

### 핵심 가설
- 자연어 처리의 평가 기법인 왕복 번역(Round-trip Translation, RTT)을 코드에 적용하여 프로그래밍 언어 간 거리를 정량적으로 도출할 수 있음$^1$
### 연구 목적

1. 프레임워크 가능성 탐색: C++를 기준으로 C, Java, Python을 오가는 왕복 번역 측정
2. LLM 모델 간 특성 비교: 오픈소스 모델(qwen2.5-coder)과 상용 모델(gpt-5.4)의 특성 및 번역 양상 대조

> 1: 조찬우, 김영훈, 우균, "왕복 번역과 고정점을 이용한 언어 거리 계산," 2025 한국정보과학회 학술발표논문집, 2025.

---

<!-- _header: 관련연구: 왕복 번역(RTT) 기반의 코드 의미 보존 -->

왕복 과정에서 발생하는 정보 손실의 크기가 곧 두 언어 사이의 "거리"를 반영한다는 가설

- 자연어 처리(NLP)에서 번역 품질을 평가하는 비지도(unsupervised) 기법(한국어 $\to$ 영어 $\to$ 한국어로 번역 후 원문과 비교)
- ICML'24에서 Allamanis 등이 제안한 Round-trip Correctness(RTC)는 벤치마크 없이 코드 LLM을 평가할 수 있는 방법론(예측(코드 $\to$ 설명) $\to$ 역변환(설명 $\to$ 코드) $\to$ 테스트를 통한 의미 동치 검증)
- 코드 RTT 과정에서 필연적으로 발생하는 정보 손실(Information Loss) 과 구조적 변형을 두 언어가 공유하는 근본적 교집합의 크기로 보고 이를 언어 간 거리로 치환함$^2$
- 의미 보존 정도를 측정하여 두 프로그래밍 언어 간의 구조적 이질성을 정량화함

> 2: Miltiadis Allamanis, Sheena Panthaplackel, Pengcheng Yin, "Unsupervised evaluation of code LLMs with round-trip correctness," ICML'24, pp. 1050–1066, 2024.

---

<!-- _header: 관련연구: 고정점(Fixed-point) 이론 기초 -->

함수 $f$에 대해 $f(x) = x$를 만족하는 값 $x$를 고정점이라 함
- 코드를 반복적으로 왕복 번역(A $\to$ B $\to$ A $\to$ B $\to$ $\dots$)할 때 더 이상 코드가 변하지 않는 상태
  - 0회 (원본): `int a = 0; for(...)`
  - 1회 왕복: `int a = 0; while(...)` (구조 변형 발생)
  - 2회 왕복: `int a = 0; while(...)` (변화 없음 $\to$ 고정점 도달)
- 고정점까지의 반복 횟수가 적을수록 두 언어가 구조적으로 유사함을 시사

코드를 반복 변환 시 더 이상 코드가 변경되지 않는 상태인 고정점에 도달하는지 여부 확인
- 고정점에 도달하기까지 걸리는 반복 횟수(Iteration count)
- 원본 코드와 수렴된 코드 간의 형태적 차이

### 실험 대상 코퍼스
- 백준 온라인 저지(BOJ)의 5개 알고리즘 문제
  - 문자열 탐색(1435), 이분 탐색(2110), 그리디(2217), 동적 프로그래밍(2579), 그래프 탐색(5567)

### 평가 기준 언어 및 구조적 이질성
- 기준 언어: C++
- 대상 언어: C (C++의 부분 집합), Java (객체지향), Python (동적 타입 및 다른 구문 체계)

### 평가 지표
1. 변경 횟수 거리: 고정점 도달까지 완료된 왕복 주기 수
2. MOSS 유사도$^3$: 스탠포드 MOSS 시스템을 사용해 원본 C++와 왕복 후 C++ 코드 비교
3. 의미 보존 여부: 왕복 코드가 테스트 입출력을 모두 통과했는지 여부

> 3: A. Aiken, "Moss: A System for Detecting Software Plagiarism," 2004.

<!-- _header: 결론 -->

1. 기존 방법은 정적 특성(문법, 키워드)에 의존하였지만, 본 연구는 LLM의 동적 번역 과정에서 나타나는 정보 손실을 거리로 사용하여 런타임 의미 보존까지 검증하는 실행 기반(execution-based) 평가를 통해 프로그램 변환 과정의 "언어 사이 거리 정량 측정법"을 제시하였다.

2. 실험 결과, `qwen2.5`은 범용적 번역 능력으로 안정적인 성능을 보였으며, `gpt-5.4`는 언어 특성에 따른 큰 성능 편차를 보였다.

3. 향후 계획은 대규모 문제 셋을 활용한 실증 검증과 언어 구조 유지 vs 단순 실행 가능성 보장 등 요구사항에 따른 최적 모델 자동 할당 프레임워크 제안 등을 연구할 예정

<!-- _header: 부록 A: MOSS(Measure of Software Similarity) -->

- 스탠포드 대학교 Alex Aiken 교수가 개발한 소프트웨어 유사도 측정 시스템 $\to$ 프로그래밍 과제의 표절 탐지

#### 동작 원리

1. 전처리: 공백/주석 제거, 변수명을 일반 토큰으로 치환 (변수명 변경에 강건)
2. K-gram 생성: 토큰화된 코드를 연속 $k$개 토큰 단위로 분할
3. Winnowing 알고리즘: 해시 윈도우를 슬라이딩하며 대표 해시(fingerprint)를 선택
4. 비교: 두 코드의 fingerprint 집합 간 공통 요소 비율로 유사도 산출

> 본 연구에서는 원본 코드와 왕복 번역 코드 사이의 구조적 유사도를 정량화하는 지표로 활용
