이 문서는 v1.5의 역사적 원고입니다. 그 문서에 기재된 모델·코퍼스·성공 수·거리·신뢰구간을 v1.6 실험의 결과로 사용하지 않습니다. 최신 원고는 [manuscript.md](../manuscript.md)와 [v1.6.docx](../v1.6.docx)입니다.
