# Command Code 두 모델 v1.6 실제 실험 실행 계획

작성·공식 문서 조회일은 2026-11-17입니다. 사용자가 승인하신 GLM-5.3과 DeepSeek V4 Pro에 대해 새 사전 점검·모델별 12슬롯 파일럿·완전성 감사·본 실험 동결·300슬롯 본 실험·보고·수치 재현을 순차 수행합니다. 기존 연동 점검의 응답은 재사용하지 않습니다.

## 생성 프로파일과 비교 조건

| 모델 | 요청 모델 ID | 요청 생성 설정 | 공통 프로파일과의 관계 |
|---|---|---|---|
| GLM-5.3 | zai-org/GLM-5.3 | temperature 0.6, top_p 0.95, max_tokens 16384, reasoning_effort low | sampling 요청값·출력 상한 유지, seed 지원 근거 부재로 생략, 추론 수준 명시 |
| DeepSeek V4 Pro | deepseek/deepseek-v4-pro | max_tokens 16384, reasoning_effort low | 추론 모드에서 temperature·top_p 무시라는 공식 제약에 따른 별도 호환 프로파일 |

공식 주소는 `https://api.commandcode.ai/provider/v1/chat/completions`입니다. 두 모델 모두 seed 지원 문서가 확인되지 않아 보내지 않습니다. 서버가 실효 설정을 확인하지 않으면 null로 보존하며 요청값을 적용값으로 복사하지 않습니다. 같은 low를 같은 추론량으로 주장하지 않습니다. 두 모델은 모델별 별도 생성 조건이며, 모델 간 동일 조건의 인과적 비교로 해석하지 않습니다. 근거 URL과 요약은 `sources.json`, 공개 모델 목록은 `catalog.json`에 있습니다.

## 고정 조건과 관문

문제 15개·C++ 출발 4경로·반복 5회·임계치 0.80/0.85/0.90·탐색 10홉·확인 1왕복·13개 기능 평가·사례 5초·컴파일 180초·900초 탐색 및 확인 전용 최대 300초·고정 JPlag 조건을 유지합니다. 파일럿은 IPOP_11729·IPOP_1992·LC_0053×4경로×1회입니다.

실제 `run_hops_campaign`의 공급자·평가·유사도·관측 저장·구조 감사 경로를 사용합니다. 파일럿 12슬롯의 구조 감사와 세 임계치 완전성이 모두 참일 때 실제 `freeze_main_design`으로 동결합니다. 기능 실패·홉 제한은 유효한 관측으로 유지하며 결과가 낮아도 설정을 바꾸지 않습니다. 무효·누락을 새 슬롯으로 바꾸거나 실패 관측을 삭제하지 않습니다. 관문이 통과하면 추가 승인 없이 본 실험을 진행합니다.

## 비용과 실행 방식

| 모델별 단계 | 비용 중단 상한(USD) | 논리 요청 상한 | 전송 상한 | 자동 통신 재시도 |
|---|---|---|---|---|
| 새 사전 점검 | 0.25 | 1 | 1 | 0 |
| 파일럿 | 50 | 144 | 432 | 최대 2회 |
| 본 실험 | 50 | 3600 | 10800 | 최대 2회 |

두 모델의 네 실험 단계 상한 합계는 200달러이고 사전 점검까지 200.50달러입니다. 이는 예상 청구액이 아닌 중단 상한입니다. 요청당 최대 입력 32768·출력 16384토큰과 0.25달러 예약을 적용합니다. 공식 단가로 계산한 최대 요청비는 GLM 약 0.117965달러·DeepSeek 피크 약 0.108134달러로 예약 이하입니다. 실제 사용량의 추정비용과 공급자 보고 청구액을 구분하고 미보고 청구액은 null입니다.

모든 API·컴파일·평가·JPlag를 한 프로세스에서 직렬 실행하며 샤드를 병렬 실행하지 않습니다. 각 모델의 preflight·pilot·main은 별도 원장·요청키·폴더를 사용합니다. 파일럿의 실제 공급자 상한은 실행 래퍼의 동결된 phase_budget_policy로 144요청에 제한하고 본 실험 설정과 계약 자체는 동일하게 유지합니다.

## 인증·소스·환경 동결

`scripts/run_commandcode_v16.py`의 인증 래퍼는 키를 프로세스 메모리에 보관하고 `provider.complete` 구간에만 CMD_API_KEY 환경을 둔 뒤 finally에서 제거합니다. 전체 실행 환경은 기존 연동 점검의 허용 목록으로 제한하므로 기능 평가·컴파일·JPlag와 보고기의 하위 프로세스에는 키가 없습니다. 키·헤더·환경 파일 내용을 출력하거나 자료로 보관하지 않습니다.

인증 비상속·예외 후 정리·phase별 예산·동일 응답 캐시 재개·독립 실행 진입점을 모의 검사했습니다. 추가한 래퍼 검사 5개가 실제 통과했습니다. 기존 core의 프롬프트·판정·호출·평가 결과를 대체하거나 모의하지 않습니다. 공급자 객체의 호출 경계만 인증 격리 객체로 감싸고 관측 반환 후의 진행 기록만 추가합니다.

파일럿 전에 실행 관련 64개 파일의 해시·스냅샷과 도구 버전·환경·자료 매니페스트·75개 기준 구현/975개 평가 및 195개 독립 계산 근거를 `source-manifest.json`과 `execution-sources/`에 보존했습니다. 준비 명령에서 실제 검증기·독립 계산기 해시·자료 전체 집합·도구 버전의 관문을 통과했습니다. 매 관측 전에 동결 소스와 설정이 같은지 확인하며 변경 시 생성을 중단하고 원자료를 보존합니다. 실행 중 래퍼를 수정하지 않습니다.

초기 디스크 여유 공간과 모델별 계약 해시는 `source-manifest.json`의 checks 항목에 실제 측정값으로 기록했습니다. 계정 권한은 새 사전 점검에서 확인하며 과거의 성공을 대입하지 않습니다.
