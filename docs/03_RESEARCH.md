# 1차: 최우선 축

## 최우선 축 1: 의미 생존 보정 고정점 거리와 확률적 고정점 이론화

- 제안서는 현재 지표(고정점까지 반복 횟수)가 언어 특성뿐 아니라 모델, 프롬프트, 디코딩 설정, 과제 난이도에 영향을 동시에 받는다는 점을 지적하고, 무엇을 거리라고 부를 수 있는지 이론적으로 재정의하는 연구를 가장 중요한 후속 논문으로 위치시키고 있습니다. 
- 특히 GPT 계열에서 Java·Python 왕복이 빠르게 “멈추지만” 의미 보존률이 0%인 사례 때문에, 단순 반복 횟수가 언어 거리를 잘 표현하지 못한다는 내부 증거가 있고, 이를 해결하기 위해  
  - 의미 보존 실패를 별도 페널티로 분리하고,  
  - 생존한 경우에만 고정점 도달 시간과 구조 변화량을 거리 성분으로 사용하며,  
  - LLM 왕복을 확률적 전이 연산자로 보고 “의미 등가류에 대한 기대 hitting time”을 정의하는 방향을 제시합니다.  
- 이 방향은 프로그램 의미론·추상 해석의 고정점 개념과 Allamanis의 RTC, EvalPlus 같은 실행 기반 평가를 한 프레임워크로 엮어, 거리 개념을 수학적으로 정교하게 만드는 작업이라 학술적 기여가 가장 크고 이론 논문으로 발전시키기 좋습니다. 

## 최우선 축 2: 다중뷰 프로그래밍 언어 거리 (실행·구조·임베딩의 통합 메트릭)

- 제안서는 현재 논문이 MOSS 하나에 의존하는 것을 비판하면서, 실행 의미, AST 편집 거리, 데이터 흐름 그래프, 임베딩 기반 유사도(CodeBLEU, CodeBERTScore 등)를 결합해 “다중 관점 언어 거리”를 구성하는 방향을 강조합니다.
- 실제로 Qwen의 C++↔Python 왕복에서 MOSS 유사도가 평균 0%인데도 테스트는 100% 통과하는 결과가 있어, 표면 구조 거리와 의미 거리의 분리가 뚜렷하다는 점이 동기 부여로 제시됩니다.
- 제안서에서는 MOSS/Winnowing, TSED, CodeBLEU, GraphCodeBERT, CodeBERTScore, 실행 통과율·트레이스 등을 한 벡터로 만들고, 차원축소나 metric learning을 통해 통합 지표를 설계하는 아이디어를 제안하며, 이를 “MOSS 의존 탈피”와 “인간 직관·실행 결과와의 상관 향상” 측면에서 높은 학술적 잠재력이 있는 연구로 평가합니다. 

## 최우선 축 3: 모델 불변 다언어 거리 지도와 언어 vs 모델 효과 분리

- 제안서는 관측된 거리 값이 언어 거리와 모델 거리, 과제·프롬프트 요인의 합성이라는 점을 반복해서 지적하고, “진짜 언어 효과”와 “모델 고유 효과”를 통계적으로 분리하는 다언어·다모델 실험을 가장 장기 영향력이 높은 방향으로 보았습니다.
- 이를 위해 MultiPL-E, XCodeEval, CodeScope, CRUXEVAL-X 같은 대규모 다언어 벤치마크를 이용해 8~12개 언어, 여러 모델 계열(GPT, Qwen, CodeT5, Code Llama 등)을 교차하고, 혼합효과 모형이나 계층 베이지안 모형으로 언어 쌍, 모델, 과제, 상호작용을 분산 분해하자는 제안을 하고 있습니다.
- 이 라인은 “LLM 유도 프로그래밍 언어 계통도(phylogeny)”를 구축해 기존 언어 계보나 인간 학습 난이도 연구와 비교하는 그림까지 포함하고 있어, 언어 이론과 코드 LLM 평가를 연결하는 큰 그림의 학술적 기여가 기대됩니다.

# 2차 우선: 설명력·응용 측면에서 의미 있는 확장들

학술적 핵심축에 비하면 상대적으로 응용·해석 쪽에 치우치지만, 논문으로 발전하기에 충분한 가치가 있는 방향입니다. 

## 언어 기능·패러다임별 거리 원인 분석

- 언어 간 거리 숫자 자체보다, 어떤 언어 기능(포인터·예외·객체 모델·고차 함수·병렬성 등)이 의미 손실과 구조 붕괴를 유발하는지 분석하는 방향이 제안되어 있습니다.
- 마이크로벤치마크를 설계해 기능별로 프로그램 쌍을 만들고, 반복 왕복에서 실패·구조 변화 패턴을 통계적으로 분석하면, PL 이론과 실무 개발자 교육 측면에서 설명력이 높은 결과를 기대할 수 있습니다. 

## 방향성 거리와 언어 공간의 기하

- 왕복 거리의 비대칭성(A→B와 B→A가 다른 경우)과 삼각 부등식 위반 여부 등을 실험적으로 조사해, metric이라기보다는 방향성 발산도(divergence) 개념으로 정식화하자는 제안입니다.
- 언어 쌍을 방향 그래프로 보고 비대칭성 지수, 삼각 부등식 위반율, 임베딩을 이용한 언어 공간 구조를 분석하는 작업은 이론적 흥미가 크지만, 고정점·다중뷰·모델 분해 축에 비해 조금 후순위로 위치해 있습니다.

## 중간 표현·경로 최적화 (IR·pseudocode 경유 변환)

- 직접 A→B보다 A→pseudocode/AST/IR→B 경로가 먼 언어쌍에서 의미 보존을 개선할 수 있다는 가설을 시험해보고, 언어 거리를 “최적 변환 경로의 비용”으로 정의하자는 응용 방향입니다.
- 이는 언어 거리 개념을 코드 변환 시스템 설계와 연결하는 응용 논문으로 적합하며, 고정점·다중뷰·모델 분해 축이 어느 정도 정리된 뒤에 이어가면 좋은 주제로 평가됩니다.

# 3차 우선: 분석 고도화 및 비교 연구들

- 코드 표절 탐지기, 언어 변환 파이프라인, 교육 커리큘럼, 멀티언어 코드 검색·RAG 시스템 등은 제안서에서 풍부하게 아이디어가 나열되어 있지만, 학술적 이론 기여보다는 시스템·응용 기여 비중이 높습니다. 

# 정리: 지금 관점에서 우선 잡으면 좋은 연구 라인

학술적 가치와 논문성(개념적 새로움·이론적 깊이·국제 학회 설득력)을 기준으로, 제안서 내부 평가와 내용을 종합하면 다음 순서를 추천할 수 있습니다.

1. 의미 생존을 보정한 고정점 기반 언어 거리 정의  
   - 의미 실패를 거리의 핵심 성분으로 포함하고, 고정점 도달 과정을 확률적·의미론적으로 재정의하는 이론·실험 논문.

2. 실행·구조·임베딩을 통합한 다중뷰 언어 거리 메트릭  
   - MOSS를 넘어서는 복합 지표를 설계하고, 인간 직관·실행 결과·기존 PL 이론과의 상관을 분석하는 메트릭 중심 논문.

3. 다언어·다모델 거리 지도와 언어 vs 모델 효과 분리  
   - MultiPL-E·XCodeEval 등 대규모 벤치마크를 활용해 언어 계통도와 모델 세대별 drift를 분석하는 데이터·통계 중심 논문.

4. 그 다음 단계에서  
   - 언어 기능·패러다임별 원인 분석,  
   - 방향성 거리·언어 공간 기하,  
   - 중간 표현 경로 최적화 및 다양한 응용 시스템  
   을 각각 개별 논문 또는 섹션으로 확장하는 로드맵이 자연스러워 보입니다.
