## 중점적으로 확장한 해석

1. 주 임계치의 도달률과 성공 조건부 평균 홉 수를 분리하고, 거리 지수가 주로 성공 표본의 비중에 좌우되는 경우를 설명하였습니다.
2. Flash의 Python·Java에서 홉 한도가, Prolog에서 기능 실패가 우세한 현상을 실제 실패 분류와 연결하였습니다. 오류 유형만으로 확인할 수 없는 구체적인 코드 생성 원인은 단정하지 않았습니다.
3. 첫 왕복의 정방향과 조건부 역방향 통과율로 생존 선택을 설명하고, GLM Prolog 성공 0건의 H·D를 결측으로 유지하였습니다.
4. 최초 도달과 다음 왕복의 확인 유지율을 구분하고, GLM의 HTTP 524 감사 후 Haskell 확인 분모 14를 적용하였습니다.
5. Flash Python–Java의 D 순서가 임계치 0.80과 0.85에서 달라지는 사례를 설명하고, 미보정 기술 구간과 확증 분석을 구분하였습니다.
6. 높은 인접 유사도와 낮은 원본 대비 유사도가 함께 나타나는 결과를 국소적인 형태 안정성으로 해석하였습니다.
7. Haskell 재귀군의 결과가 두 모델에서 반대 방향으로 나타나는 점을 제시하고, 문제 특성·언어·모델의 인과 효과를 분리하지 않았음을 명시하였습니다.
8. 측정 불가를 유사도 0이나 기능 실패로 바꾸지 않고, GLM 사후 측정 실패 처리와 Flash 원관측의 차이, 분모 선택의 산술적 경계를 제시하였습니다.

## 수치·자료 검증

본문에는 표 10개와 그림 2개가 있습니다. 표 8개와 그림 2개는 저장한 CSV 및 감사 원표에서 자동 생성하고, 나머지 설정표와 결측 경계표는 실제 설정·분모에 맞추어 작성하였습니다. 원자료 SHA-256과 표 내용은 해석 근거 JSON에 기록합니다.

검증 스크립트는 각 모델의 300개 본 실험 관측에 대해 주 임계치의 성공 수·유효 분모·H·D와 경로당 75슬롯 범주의 합을 다시 계산합니다. 확인 원표의 감사 후 5/9/1 분류, 총 확인 유지 수, 실제 기술 비교 구간의 종류도 대조합니다. 유료 모델 호출·평가 재실행·원관측 변경은 수행하지 않습니다.

```powershell
uv run --no-sync python scripts/build_v16_manuscript.py
uv run --no-sync black --check scripts/build_v16_manuscript.py
```

스크립트는 원고 표 블록과 PNG·PDF 그림, 편집용 Word 문서, 원고 해석 근거 JSON을 다시 만듭니다. Word 문서는 본문의 장·표·그림·참고 링크를 포함하는 단일 열 편집본이며, 학술지 투고 양식의 최종 조판본은 아닙니다. 생성 후 표 10개와 삽입 그림·본문 구조를 검사합니다. 그림의 축·범례·결측 표시도 시각적으로 확인하였습니다.

## 문헌 확인과 판본 차이

선행 연구의 자연어 왕복 번역 논문은 저장된 PDF를 읽고 서지정보를 확인하였습니다. 코드 번역의 NeurIPS 공식 논문, 왕복 정확성의 PMLR 논문, MultiPL-E의 arXiv v4, JPlag의 학술지 원문 및 버전 고정 문서, DeepSeek의 설정 문서도 직접 조회하였습니다. 원문에서 확인한 범위를 넘어 해당 문헌이 본 실험의 순위나 인과 해석을 검증한다고 쓰지 않았습니다.

MultiPL-E는 실제 열람한 arXiv v4의 제목과 연도를 수록했습니다. v1.5의 학술지 판본 제목을 확인 없이 같은 항목으로 옮기지 않았습니다. 기존 참고문헌 가운데 새 본문에서 직접 사용하지 않은 문헌은 일괄 복사하지 않았습니다. 이 확인은 원고에 사용한 주장·서지 범위이며, 체계적 문헌고찰 전체를 수행했다는 의미는 아닙니다.

v1.5의 미래 접수일과 미완성 저자 소개는 새 원고에 옮기지 않았습니다. 기존 저자·소속·연락처는 유지하였고 v1.5와 원자료는 수정하지 않았습니다.

## 제출 전 남은 편집

- 학술지의 국문·영문 초록, 분량·단 구성, 참고문헌 표기와 저자 정보 최종 확인
- 사전 확증 분석의 완전성 미충족을 유지한 채 제출할 분석 범위에 대한 저자 검토
- 원고에 수록한 기술통계·해석의 공동저자 검토와 실제 코드 주석의 추가 분석 여부 결정
- 최종 투고용 Word 조판과 페이지 나눔·그림 해상도 확인

현재 결과를 보완하기 위한 새 유료 실험이나 측정 정책 변경은 이 원고 작성 범위에 포함하지 않았습니다.
